# Security

Deepslate Works is a hobby project run for a group of friends. Security reports are welcome and handled on a best
effort basis.

## Reporting a problem

Use GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose
**Report a vulnerability**. Only the maintainer sees the report.

Please don't open a public issue, pull request or discussion for a security problem.

## In scope

- The website and its api (`apps/web`, `apps/api`)
- The Windows launcher and its installer (`installer/`)
- The modpack lock and the build tooling (`modpack/`, `packages/modpack`, `tools/`)
- The GitHub workflows (`.github/`)

## Out of scope

- Bugs inside third-party Minecraft mods or in Minecraft itself: please report those to the mod's authors or to
  Mojang
- Gameplay exploits
- Anything that needs physical access to a player's PC

## Supported versions

- The launcher version currently offered on the site. If you are on an older launcher, update first and check the
  problem is still there.
- The site as deployed from `main`.

## What to expect

- An acknowledgement within 7 days.
- A fix as time allows.
- Credit in the fix if you want it; say so in the report.
