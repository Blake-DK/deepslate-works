Deepslate Works - one-click install

1. Install the normal Minecraft Launcher from minecraft.net and open it once.
2. Double-click Setup.bat and wait for the green ticks.
3. Open the Minecraft Launcher, choose "Deepslate Works" next to Play, press Play.

Run Setup.bat again any time to update the mods. It never touches your normal Minecraft.
To remove: delete the "Deepslate Works" profile in the launcher and the .minecraft-deepslate-works folder in %APPDATA%.
The installer owns the mods folder of that profile: anything you drop in there is removed on the next run.
